Visualizador del catálogo de Objetos Geográficos IDERA

Aplicación web interactiva para la exploración del catálogo de objetos geográficos de la Infraestructura de Datos Espaciales de la República Argentina (IDERA).


Herramientas utilizadas:

React 19.1.1 – Última versión estable de React

Next.js 14 – Framework con App Router integrado

Tailwind CSS v4 – Estilos modernos y adaptables

Radix UI – Componentes accesibles y personalizables

TypeScript – Tipado estático para mayor robustez

Lucide React – Iconografía limpia y consistente


Requisitos Previos

Node.js 18.17 o superior

Gestor de paquetes: npm, yarn, pnpm o bun

Funcionalidades

Dashboard Interactivo

Navegación jerárquica: Categorías → Subcategorías → Objetos

Búsqueda instantánea en cada nivel

Visualización de atributos en modales

Códigos de color por categoría

Badges por tipo de geometría (Punto, Línea, Polígono)

Etiquetas DByF (Datos Básicos y Fundamentales)


Funciones de Cada Objeto

Descarga de simbología (JSON)

Enlace directo al Visualizador IDERA

Acceso al Catálogo de Metadatos

Scripts Disponibles
npm run dev      # Servidor de desarrollo
npm run build    # Compilación para producción
npm run start    # Servidor de producción
npm run lint     # Análisis de código

Compatibilidad

 React 19.1.1

 Node.js 18+

 Navegadores modernos (Chrome, Firefox, Safari, Edge)

 Diseño responsive
